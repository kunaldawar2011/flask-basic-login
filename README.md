Flask Basic Login

«My first basic Flask project 🚀»

A simple login form built using Python Flask, HTML, and CSS. Users enter their name and receive a personalized welcome message after submitting the form.

---

✨ Features

- 📝 Name input form
- 📩 POST request handling
- 👋 Personalized welcome message
- 🎨 CSS styling
- 🖱️ Hover effects and transitions
- 📄 HTML templates using Jinja

---

🛠️ Technologies Used

- 🐍 Python — Backend
- ⚡ Flask — Web framework
- 🌐 HTML — Page structure
- 🎨 CSS — Styling

---

📂 Project Structure

Flask-Basic-Login/
│
├── app.py
│
└── templates/
    ├── login.css.html
    └── logged.html

---

🚀 Getting Started

1. Install Flask

pip install flask

2. Run the application

python app.py

3. Open in your browser

Visit:

http://127.0.0.1:5000

Enter your name and click Submit!
